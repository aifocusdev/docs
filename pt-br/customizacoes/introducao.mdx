## 🚀 Otimizações de Performance

### Problema Identificado

O Chatwoot original apresentava **lentidão crítica** ao carregar conversas e Kanban devido a:

- Queries N+1 (200-500+ queries por página)
- Falta de índices no banco de dados
- Carregamento simultâneo de todas as imagens
- Sem cache de avatares

### Solução Implementada

✅ **Eager Loading Completo**
```ruby
# app/finders/conversation_finder.rb
@conversations.includes(
  :inbox, :team, :contact_inbox, :funnel_mappings,
  :conversation_products, :conversation_appointments,
  :labels,
  assignee: [avatar_attachment: :blob],
  contact: [avatar_attachment: :blob]
)
```

✅ **Índices de Banco de Dados**
```ruby
# db/migrate/..._add_performance_indexes_to_conversations.rb
add_index :conversations, [:account_id, :status, :assignee_id]
add_index :conversations, [:inbox_id, :status]
add_index :conversations, [:account_id, :last_activity_at]
add_index :conversation_funnel_mappings, [:funnel_id, :stage_name]
```

✅ **Lazy Loading de Imagens**
```vue
<img loading="lazy" :src="avatar_url" />
```

✅ **Cache de Active Storage**
```ruby
# config/initializers/active_storage_performance.rb
Rails.cache.fetch(cache_key, expires_in: 15.minutes)
```

### Resultado

| Métrica | Antes | Depois | Melhoria |
|---------|-------|--------|----------|
| **Tempo de carregamento** | 5-10s | 1-2s | **80% mais rápido** |
| **Queries por página** | 200-500+ | 3-10 | **95% redução** |
| **Uso de banda** | 100% | 30-40% | **60% economia** |

📖 **[Ver documentação completa de performance](/pt-br/customizacoes/performance)**

## 🐛 Correção de Bugs Críticos

### Problema: Conversas Órfãs

Identificamos erros `404` e `500` causados por dados órfãos:

```
❌ GET /api/v1/accounts/1/conversations/161/messages
   → 500 Internal Server Error

❌ GET /api/v1/accounts/1/contacts/undefined/contactable_inboxes
   → 404 Not Found
```

**Causa Raiz:**
- Conversas permaneciam no banco após contatos serem deletados
- Frontend tentava carregar dados de contatos inexistentes
- MessageFinder quebrava com `conversation.contact = nil`

### Solução Implementada

✅ **Filtrar Conversas Órfãs no Backend**
```ruby
# app/finders/conversation_finder.rb
@conversations = @conversations.joins(:contact)
  .where.not(contacts: { id: nil })
```

✅ **Tratamento de Erro no Frontend**
```javascript
// app/javascript/dashboard/routes/.../ContactInfo.vue
if (id && id !== 'undefined' && !isNaN(id)) {
  this.$store.dispatch('contacts/fetchContactableInbox', id)
    .catch(error => {
      if (error?.response?.status === 404) {
        console.warn(`Contact ${id} not found (deleted)`);
      }
    });
}
```

✅ **Script de Limpeza**
```bash
# Limpar dados órfãos
RAILS_ENV=production DELETE_ORPHANED=true \
  bundle exec rake data_cleanup:all
```

### Resultado

- ✅ 8 conversas órfãs removidas
- ✅ Zero erros 404/500 relacionados a contatos
- ✅ Frontend não quebra mais
- ✅ Script de manutenção disponível

## 🎨 Features Exclusivas

### 1. Sistema de Funis (Kanban/Pipeline)

Sistema completo de gestão de vendas estilo Kanban:

**Recursos:**
- ✅ Múltiplos funis personalizáveis
- ✅ Drag & drop de cards entre estágios
- ✅ Templates de funis pré-configurados
- ✅ Checklists por estágio
- ✅ Timers de permanência
- ✅ Múltiplos agentes por conversa

**Exemplo de Uso:**
```
Funil de Vendas:
├── 🆕 Novo Lead
├── 📞 Em Contato
├── 💰 Proposta Enviada
├── ✅ Fechado
└── ❌ Perdido
```

📖 **[Ver documentação de Funis](/pt-br/customizacoes/funis)**

### 2. Produtos em Conversas

Vincule produtos às conversas para rastreamento de vendas:

```json
{
  "id": 1,
  "conversation_id": 123,
  "product_name": "Plano Premium",
  "product_value": 299.90,
  "quantity": 1,
  "notes": "Cliente interessado"
}
```

### 3. Agendamentos

Sistema de agendamentos integrado:

```json
{
  "id": 1,
  "conversation_id": 123,
  "scheduled_at": "2025-01-20T14:00:00Z",
  "title": "Reunião de Apresentação",
  "notes": "Apresentar plano enterprise"
}
```

### 4. Notas Internas

Notas privadas visíveis apenas para equipe interna:

```ruby
# Criar nota interna
POST /api/v1/accounts/:account_id/conversations/:id/notes
{
  "content": "Cliente tem budget aprovado",
  "user_id": 1
}
```

## 🔌 Integrações Melhoradas

### WhatsApp Multi-Provider

Suporte para **3 providers diferentes**:

1. **Evolution API** - Código aberto, self-hosted
2. **WAHA** (WhatsApp HTTP API) - Docker-based
3. **UAZ API** - Provider brasileiro

```ruby
# app/controllers/api/v1/accounts/inboxes_controller.rb
post :recreate_evolution_instance
post :recreate_waha_instance
post :connect_uazapi_instance
```

### Instagram Business Login

Integração melhorada com Instagram via Business Login:

```ruby
# Configuração simplificada sem necessidade de App Review
facebook_app_id: ENV['FB_APP_ID']
instagram_business_account_id: auto_detect
```

### Notificame Integration

Sistema de notificações brasileiro integrado:

```ruby
# app/controllers/api/v1/accounts/notificame/channels_controller.rb
GET /api/v1/accounts/:account_id/notificame/channels
```
