# 📚 Central de Ajuda (Help Center)

Crie uma base de conhecimento para clientes encontrarem respostas sozinhos e alimentar seus Agentes de IA.

---

## 📋 O que é a Central de Ajuda?

**Central de Ajuda** é um portal de conhecimento onde você publica:

- 📖 **Artigos**: Guias e tutoriais
- ❓ **FAQ**: Perguntas frequentes
- 🎥 **Vídeos**: Demonstrações
- 📝 **Documentação**: Manuais completos
- 🔧 **Troubleshooting**: Soluções de problemas

## 🚀 Configurar Central de Ajuda

### Passo 1: Ativar

1. **"Configurações"** → **"Central de Ajuda"**
2. Clique em **"Ativar"**
3. Defina URL:
   ```
   https://ajuda.seudominio.com
   ```

### Passo 2: Personalizar

**Branding:**
- Logo da empresa
- Cores da marca
- Favicon
- Banner de capa

**Informações:**
- Nome da empresa
- Descrição
- Contato de suporte
- Links de redes sociais

## 📝 Criar Conteúdo

### Estrutura

```
Central de Ajuda
├── 📁 Categoria 1: Começando
│   ├── 📄 Como criar conta
│   ├── 📄 Primeiro acesso
│   └── 📄 Configurações iniciais
├── 📁 Categoria 2: Produtos
│   ├── 📄 Catálogo completo
│   ├── 📄 Como comprar
│   └── 📄 Rastreamento de pedido
└── 📁 Categoria 3: Pagamentos
    ├── 📄 Formas de pagamento
    ├── 📄 Parcelamento
    └── 📄 Dúvidas sobre cobrança
```

### Criar Categoria

1. **"Central de Ajuda"** → **"Nova Categoria"**
2. **Nome**: "Começando"
3. **Descrição**: "Primeiros passos na plataforma"
4. **Ícone**: Escolha um emoji 🚀
5. **Salvar**

### Criar Artigo

1. **Escolha Categoria**
2. **"Novo Artigo"**
3. Preencha:

**Título:**
```
Como criar uma conta?
```

**Conteúdo:**
```markdown
# Como criar uma conta

Criar sua conta é simples e rápido!

## Passo a passo

1. Acesse www.seusite.com
2. Clique em "Criar Conta"
3. Preencha:
   - Nome completo
   - Email
   - Senha (mínimo 8 caracteres)
4. Clique em "Registrar"
5. Confirme seu email

## Dúvidas?

Se tiver problemas, entre em contato:
- 📧 Email: suporte@seusite.com
- 💬 Chat: Disponível 9h-18h
```

**SEO:**
- **Slug**: `como-criar-conta`
- **Meta Description**: "Aprenda a criar sua conta em 5 passos simples"
- **Tags**: criar conta, registro, cadastro

4. **Publicar**

## 🔍 SEO e Descoberta

### Otimização para Busca

Para aparecer no Google:

**1. Títulos Claros:**
✅ "Como cancelar minha assinatura"  
❌ "Cancelamento"  

**2. Use Palavras-chave:**
Inclua termos que clientes buscam

**3. Links Internos:**
Conecte artigos relacionados

**4. URL Amigável:**
✅ `/ajuda/como-cancelar-assinatura`  
❌ `/ajuda/artigo-123`  

### Busca Interna

Clientes podem buscar na Central:
```
🔍 Buscar...  "como cancelar"

Resultados (3):
📄 Como cancelar minha assinatura
📄 Política de cancelamento
📄 Reembolso após cancelamento
```

## 🤖 Integração com IA

Agentes de IA usam artigos como base de conhecimento!

**Como funciona:**

```
Cliente: Como cancelo minha assinatura?

🤖 IA:
- Busca na Central de Ajuda
- Encontra artigo relevante
- Resume resposta
- Envia link do artigo completo

Resposta:
"Para cancelar, acesse Minha Conta > Assinaturas 
e clique em 'Cancelar'. Mais detalhes aqui: 
[link do artigo]"
```

**Melhora IA:**
Quanto mais artigos completos, melhor a IA responde!

## 💡 Melhores Práticas

### Conteúdo

✅ **Seja visual**: Use prints, GIFs, vídeos  
✅ **Passo a passo**: Quebre em etapas numeradas  
✅ **Linguagem simples**: Sem jargão técnico  
✅ **Exemplos práticos**: Mostre casos reais  

### Organização

✅ **Categorias claras**: Fácil navegação  
✅ **Títulos descritivos**: Cliente sabe o que esperar  
✅ **Tags consistentes**: Facilita busca  
✅ **Artigos relacionados**: Sugira leituras  

### Manutenção

✅ **Atualize regularmente**: Produtos mudam  
✅ **Revise feedbacks**: Artigo não foi útil? Melhore  
✅ **Remova obsoletos**: Desative artigos antigos  
✅ **Monitore busca zero**: O que clientes não encontram?
