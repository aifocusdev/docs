# 💬 Respostas Rápidas (Canned Responses)

Crie bibliotecas de mensagens prontas para responder clientes rapidamente sem digitar tudo sempre.

---

## 📋 O que são Respostas Rápidas?

**Respostas Rápidas** (Canned Responses) são mensagens salvas que você pode inserir com atalho:

```
Cliente: Qual o horário de funcionamento?

Agente digita: /horario

Sistema insere:
"Olá! Nosso horário de atendimento é:
Segunda a Sexta: 9h às 18h
Sábado: 9h às 13h
Domingo: Fechado"
```

## 🆕 Criar Resposta Rápida

1. **"Configurações"** → **"Respostas Rápidas"**
2. **"Nova Resposta"**
3. Preencha:

**Atalho (Short Code):**
```
/horario
```

**Conteúdo:**
```
Olá! Nosso horário de atendimento é:
📅 Segunda a Sexta: 9h às 18h
📅 Sábado: 9h às 13h
🔒 Domingo: Fechado

Posso ajudar em algo mais?
```

**Visibilidade:**
- 🌍 **Pública**: Todos agentes
- 👤 **Privada**: Só você
- 👥 **Por Time**: Time específico

4. **Salvar**

## 💡 Usar Variáveis

Personalize mensagens automaticamente:

### Variáveis Disponíveis

**Do Agente:**
```
{{agente.nome}} - Nome do agente
{{agente.email}} - Email do agente
```

**Do Contato:**
```
{{contato.nome}} - Nome do cliente
{{contato.email}} - Email do cliente
{{contato.telefone}} - Telefone
```

**Da Empresa:**
```
{{empresa}} - Nome da empresa
```

**Customizadas:**
```
{{contato.plano}} - Atributo personalizado
{{contato.cidade}} - Atributo personalizado
```

### Exemplo com Variáveis

**`/oi-personalizado`**
```
Olá, {{contato.nome}}! 👋

Prazer em falar com você!
Sou {{agente.nome}} do time {{empresa}}.

Vejo aqui que você é cliente {{contato.plano}}.
Como posso ajudá-lo(a) hoje?
```

**Resultado real:**
```
Olá, João Silva! 👋

Prazer em falar com você!
Sou Maria Santos do time Acme Corp.

Vejo aqui que você é cliente Premium.
Como posso ajudá-lo(a) hoje?
```

## 🖱️ Usar Resposta Rápida

### Método 1: Atalho (Mais Rápido)

```
1. Na caixa de mensagem, digite: /
2. Sistema mostra lista de respostas
3. Continue digitando para filtrar: /hora
4. Pressione Enter ou clique
5. Mensagem é inserida
6. (Opcional) Edite antes de enviar
7. Envie!
```

### Método 2: Menu

```
1. Clique no ícone ⚡ próximo à caixa de mensagem
2. Busque ou navegue pelas respostas
3. Clique na desejada
```

### Método 3: Busca

```
1. Digite / + buscar
2. Ex: "/entrega"
3. Filtro instantâneo
```

## 💬 Diferenças

| Recurso | Respostas Rápidas | Macros | Automações |
|---------|-------------------|---------|------------|
| **Trigger** | Manual (agente) | Manual (agente) | Automático |
| **Uso** | Inserir texto | Múltiplas ações | Regras condicionais |
| **Exemplo** | Mensagem pronta | "Resolver + Label" | "Fora horário → msg" |
| **Quando** | Resposta comum | Fluxo repetitivo | Trigger automático |

**Use todos juntos:**
```
1. Automação detecta "fora horário"
2. Envia resposta rápida /fora-horario
3. Aplica macro "Fora Horário" (label + status)
```

## 💡 Melhores Práticas

### Conteúdo

✅ **Tom consistente**: Mantenha brand voice  
✅ **Revise ortografia**: Sem erros!  
✅ **Emojis com moderação**: 😊 Sim, mas não exagere 😍💯🔥  
✅ **Personalize**: Use variáveis

### Organização

✅ **Atalhos curtos**: `/oi` não `/mensagem-saudacao-inicial`  
✅ **Atalhos óbvios**: `/horario` não `/h392`  
✅ **Sem duplicatas**: Uma resposta por propósito  
✅ **Mantenha atualizado**: Políticas mudam

### Governança

✅ **Aprovação**: Gerente aprova novas respostas  
✅ **Treinamento**: Mostre respostas para novos agentes  
✅ **Revisão trimestral**: O que ainda é relevante?
